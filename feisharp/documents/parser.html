Parser 概述

FeiSharp Parser 是一个用于解析和执行 FeiSharp 脚本语言的解析器。它支持变量声明、函数定义、控制流、类系统以及多种内置功能。

版本信息： FeiSharp 10.0 - 支持动态类型、类继承、异常处理、反射调用等高级特性。 
// Parser 主要结构
public class Parser
{
    // 核心数据
    private List<Token> _tokens;
    private int _current;
    public Dictionary<string, object> _variables;
    public Dictionary<string, FunctionInfo> _functions;
    internal Dictionary<string, ClassInfo> _classInfos;
    
    // 主要入口
    public void ParseStatements(string funcName = "");
}

架构设计

Parser 采用递归下降解析器设计模式，包含以下核心组件：

核心数据结构

  • _tokens: 词法分析器生成的令牌列表
  • _variables: 存储变量名和值的字典 (支持动态类型)
  • _functions: 存储函数信息的字典 (支持可见性修饰符)
  • _classInfos: 存储类信息的字典 (支持继承)
  • _results: 存储函数返回值的字典
  • _variableInfos: 存储变量元信息 (可见性, 静态, 只读)

可见性修饰符

  • public: 公开访问
  • private: 私有访问 (默认)
  • protected: 受保护访问
  • static: 静态成员
示例：类成员修饰符
class MyClass {
    public static var Version = "1.0";
    private var _data = 0;
    protected static function Helper() {
        return "helper";
    }
}

// 在函数参数中直接使用
print(2 as string);          // 输出 "2"

类系统

FeiSharp 支持面向对象编程，包括类定义、继承、访问控制等：

示例：类的定义与继承
// 基类
class Animal {
    public var name = "";
    public var age = 0;
    
    public function speak() {
        print("Animal speaks");
    }
}

// 子类 (继承)
class Dog : Animal {
    public var breed = "Unknown";
    
    public function speak() {
        print("Woof! Woof!");
    }
    
    public function fetch() {
        print(name + " fetches the ball");
    }
}

// 使用类
var dog = Dog();
dog.name = "Buddy";
dog.speak();  // 输出 "Woof! Woof!"
dog.fetch();  // 输出 "Buddy fetches the ball"
类特性：
  • 支持 public, private, protected 访问控制
  • 支持 static 静态成员
  • 支持单继承 (使用 : 语法)
  • 支持构造函数 (constructor 或类名)
  • 支持 this 和 base 关键字

导入系统

FeiSharp 支持模块化的导入系统：

示例：导入模块
// 导入系统命名空间
import "FeiSharp.IO";
import "FeiSharp.Net";
import "FeiSharp.System";
import "FeiSharp.Text.Json";

// 导入标准库文件
import "$prelude.fsc";   // 基础库 (默认已导入)
import "$math.fsc";      // 数学库
import "$text.fsc";      // 文本库

// 导入项目文件
import "~/utils.fsc";    // 当前目录下的工具库
import "~/lib/helper.fsc"; // 子目录中的库
